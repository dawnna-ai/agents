# PJ

PJ is a reusable Pickle Jar Run discovery plugin built from the supplied Agent Definition and Operating Brief. Both sources are preserved in skills/pickle-jar-run/references/. Selling Certainty circle and charcoal icons support default and dark appearances.

Provide the active Client Project Brief, confirmed Full or Scoped discovery requirement, current objective, authorized Airtable base/table/view references and applicable 6ix Framework — Master. Connected Airtable tooling is supplied separately; this skills-only package includes no server, credentials or client records.

Try: “PJ, here is the client’s latest answer. Recommend one next question, why and what you are tracking.” Or: “PJ, assess scope-specific sufficiency and prepare the PJR8 handoff to Clyde.”

PJ supports Dawnna’s facilitation, preserves client meaning and boundaries, captures durable intelligence at checkpoints and stops at discovery handoff. Installing the plugin does not start a client session, change schema, message Clyde or authorize external actions.
