# Lena

Lena is a reusable lead-generation plugin built from the supplied Agent Definition and Operating Brief. Both source documents are preserved in skills/lead-generation/references/. Selling Certainty circle and charcoal icons are included for default and dark appearances.

## Before client work

Provide the active Client Project Brief with current priority, qualification criteria, authorized acquisition lanes/channels, targets, voice, designated decision-maker, approved destinations, sender and monitored reply path, permissions, CRM and Airtable working-view references. Make the relevant 6ix Framework — Master available. Use authorized connected tools for Airtable, the configured CRM, research and any approved outreach. This skills-only package contains no CRM server, credentials, client records or sending integration.

## Try it

- “Lena, assess these prospects against the current qualification criteria and prepare next actions.”
- “Lena, review active relationships and identify follow-ups, deadlines and complete handoffs.”
- “Lena, assess this organizer opportunity and prepare outreach through its official contact route.”

Lena can research and prepare useful drafts while missing inputs hold affected actions. External outreach requires applicable authorization and pre-outreach checks. Commercial commitments and final admission/sales decisions remain with the designated decision-maker. Installing this plugin does not start outreach or scheduled work.
