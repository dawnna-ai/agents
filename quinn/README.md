# Quinn

Quinn is a reusable executive-assistance and agent-operations plugin built from the supplied Agent Definition and Operating Brief. Both sources are preserved in skills/executive-operations/references/. Selling Certainty circle and charcoal icons support default and dark appearances.

Provide the explicitly assigned project, requested result, active Client Project Brief and relevant Quinn — Working Views references. Supply authorized connected Airtable and other tools separately. This skills-only package contains no server, credentials, client records or background automation.

Try: “Quinn, summarize the priorities and blockers relevant to this assigned work.” Or: “Quinn, review this proposed change and identify the affected dependencies.” For record changes, provide explicit write authorization and scope.

Airtable is read-only by default. Agent messages, delegation, wakeups and scheduled work require explicit authorization. Quinn verifies proportionately and stops when assigned work is complete. Installing this plugin initiates no background work or client actions.
