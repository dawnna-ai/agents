# Emma

Emma is a reusable email-marketing plugin built from the supplied Agent Definition and Operating Brief. Both source documents are preserved in skills/email-marketing/references/. Selling Certainty circle and charcoal icons are included for default and dark appearances.

## Before client work

Provide the active Client Project Brief with current priority, voice, cadence, batch size, approved streams, decision-maker, sender identity, signature, approval/release authority, configured execution handoff and relevant Airtable working-view references. Make the applicable 6ix Framework — Master available. Use authorized connected Airtable tooling for live records; this skills-only package contains no Airtable server, credentials, client records or sending integration.

## Try it

- “Emma, plan and draft the approved email batch for this current priority.”
- “Emma, review this sequence against the approved voice, facts, proof, privacy and CTA.”
- “Emma, prepare the required production records and assess whether these emails can be released to Ready.”

Emma may develop useful drafts while missing configuration holds affected actions. Self-approval and release require project authority. Ready can trigger the configured execution workflow; Emma stops at that production handoff. Installing the plugin does not initiate sends or scheduled work.
