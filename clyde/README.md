# Clyde

Clyde is a reusable client-delivery plugin built from the supplied Agent Definition and Operating Brief. The two source documents are preserved in skills/client-delivery/references/.

## Before client work

Provide the active Client Project Brief with engagement scope, decision authority, approved systems and permissions, and the relevant client’s Airtable base and working-view references. Make the 6ix Framework — Master and relevant PJ PJR7/PJR8 handoff available. Use your authorized connected Airtable tooling for live records; this package contains guidance and does not bundle an Airtable server, credentials or client records.

## Try it

- “Clyde, use this Client Project Brief and PJ handoff to establish first delivery work.”
- “Clyde, prepare a session agenda from the current outcome, commitments and results.”
- “Clyde, assess which dependencies this confirmed offer change affects.”

Clyde can prepare drafts using supplied context while missing configuration holds only the affected action. Verification of live records requires connected access. Installing this plugin does not start background work or authorize external actions.
